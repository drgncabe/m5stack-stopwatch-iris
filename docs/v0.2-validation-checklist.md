# Iris v0.2 Hardware Validation Checklist

Use this checklist as the final v0.2 milestone gate before starting larger companion-app work. Compilation is required, but it is not a substitute for testing on the physical M5Stack StopWatch.

Software validation can confirm that the firmware builds and that the architecture-level surfaces still exist. The remaining checkboxes require physical-device validation on the StopWatch.

Software validation:

- [ ] Current branch is based on the latest `main`.
- [ ] `pio run` completes successfully.
- [ ] Firmware version shown in `include/iris/AppConfig.h` matches the expected diagnostics version.
- [ ] Open issues are reviewed and any known remaining defects are documented before v0.2 is closed.

## Build And Upload

- [ ] Firmware uploads successfully to the M5Stack StopWatch.
- [ ] Device boots without a crash loop or unexpected reset.
- [ ] Diagnostics window reports the expected firmware version.
- [ ] Device Info shows reasonable heap, PSRAM, sketch used, and sketch free values.

## Watch Face

- [ ] Watch launches by default after boot.
- [ ] Time is visible and updates at the expected interval.
- [ ] Date appears when the date widget is enabled.
- [ ] Battery appears at the top center when enabled.
- [ ] WiFi status appears when enabled.
- [ ] Active theme colors render correctly.
- [ ] Low-power watch face mode renders correctly.
- [ ] Screen dim and screen sleep occur at configured timeouts.
- [ ] Touch or BtnA wakes the display from sleep.

## Time, RTC, And NTP

- [ ] RTC availability is reported correctly.
- [ ] Automatic time sync can be enabled and disabled.
- [ ] NTP sync succeeds when WiFi is connected.
- [ ] Manual date/time entry still works.
- [ ] Country, date format, time format, and timezone settings persist after reboot.

## Menu And Input

- [ ] Tap or BtnA opens the main menu from the watch face.
- [ ] Dragging up/down scrolls menus one item at a time without racing to the end.
- [ ] Press-and-hold selects the highlighted menu item.
- [ ] BtnA advances menu selection.
- [ ] BtnB selects the highlighted item.
- [ ] First menu item is accessible.
- [ ] Last menu item is accessible.
- [ ] Back and Back to watch entries are easy to select.
- [ ] Footer hints remain visible and unclipped on round menus.
- [ ] Menu highlighting and haptic feedback feel consistent.

## Settings

- [ ] Volume changes persist and test tone works.
- [ ] Display brightness changes apply immediately.
- [ ] Dim brightness, dim timeout, and sleep timeout persist.
- [ ] Touch delay changes persist.
- [ ] Theme and widget settings persist.
- [ ] Status light setting changes persist.
- [ ] Power profile changes persist.
- [ ] Auto-rotation can be enabled and disabled.

## WiFi And Web Configurator

- [ ] Saved WiFi connects automatically when enabled.
- [ ] WiFi can be disabled and re-enabled.
- [ ] Setup AP starts and shows a usable network name.
- [ ] Setup AP accepts new credentials.
- [ ] Saved network can be forgotten.
- [ ] Web Dashboard loads on a connected network.
- [ ] Web Display, Touch, Sound, Theme, Power, Device, Apps, and WiFi pages load.
- [ ] Web precise controls show unsaved changes before Save.
- [ ] Cancel restores unsaved web control values.
- [ ] Mobile web navigation collapses and remains usable on a phone-sized browser.
- [ ] `/api/device`, `/api/apps`, `/api/settings`, and WiFi API endpoints return valid JSON.
- [ ] Saved WiFi passwords are not displayed.

## Apps And Navigation

- [ ] Watch app reports `system.watch`.
- [ ] Settings app reports `system.settings`.
- [ ] Development app reports `system.development`.
- [ ] Apps page lists registered apps with lifecycle and update-class details.
- [ ] Repeated app switching does not crash or visibly degrade memory.
- [ ] Fidgets menu opens.
- [ ] Wheel fidget responds to touch and haptics.
- [ ] Poppers fidget responds to touch and IMU gravity.
- [ ] Kaleidoscope fidget spins smoothly.
- [ ] Gravity ball responds to IMU gravity.
- [ ] Exiting fidgets returns to the fidgets menu.

## Development And Diagnostics

- [ ] Development menu opens from Settings.
- [ ] Hardware Diagnostics opens from Development.
- [ ] System diagnostics show firmware, CPU, uptime, heap, PSRAM, and flash.
- [ ] Memory diagnostics show heap, minimum heap, PSRAM, sketch used, and sketch free.
- [ ] Display diagnostics can test display off and brightness.
- [ ] Audio diagnostics can run a tone and restore audio.
- [ ] Input diagnostics show touch coordinates and button state.
- [ ] BMI270 diagnostics show raw accel and gyro values.
- [ ] WiFi diagnostics show status, SSID, IP, radio, sleep, and portal status.
- [ ] Power diagnostics show battery, charging, display state, profile, CPU, and idle dim/off values.
- [ ] RTC diagnostics show RTC and time-sync status.
- [ ] Haptic diagnostics pulse and stop the vibration motor.
- [ ] Bootloader menu enters ESP32-S3 download mode and Windows recognizes the device.

## Power, Heat, And Idle Behavior

- [ ] Balanced profile feels responsive in normal watch and menu use.
- [ ] Runtime profile reduces CPU/loop activity without breaking input.
- [ ] Performance profile keeps fidgets smooth.
- [ ] WiFi-on-demand shuts WiFi off after sync or timeout.
- [ ] Device temperature feels reasonable after several minutes on the watch face.
- [ ] Device temperature feels reasonable after several minutes in menus.
- [ ] No unexpected speaker output or high-pitched USB-powered whine is heard.

## Persistence

- [ ] Reboot preserves WiFi enabled state and saved credentials.
- [ ] Reboot preserves theme, widgets, brightness, power, touch, date/time, and status light settings.
- [ ] Reboot preserves IMU calibration offsets.
- [ ] Reboot does not clear expected diagnostics/runtime state beyond normal uptime counters.
